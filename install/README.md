# Installers

Zero-input one-liners that install the DDNS client as a service. See the
[user guide](../docs/user-guide.md#adding-a-machine) for usage.

- `install.sh`: Linux (systemd) and macOS (launchd)
- `install.ps1`: Windows (service)

The Worker serves these at `https://ddns.apps.joaoopereira.com/install.sh` and `/install.ps1`.
